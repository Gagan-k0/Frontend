Overview
We are building the complete platform for WhatBoutMe FZE (Roweena Britto, brain health
coach), end to end: from the public website through to certification. The current site is
whatboutme.com, built on GoDaddy Website Builder. We replace it with our own Next.js
website and a custom Learning Management System (LMS) on the same domain to run
the 11 Steps to U certification program online.
The platform must let a learner discover the program, pay, sign an agreement, join a batch,
attend live sessions, work through 11 locked steps, pass quizzes and a final exam, and
receive a certificate. Roweena and her team must run all of this from an admin panel
without a developer.
Guiding principles
One login per person, with what they see decided by their role.
Program content is view-only. Nothing a learner watches or reads should be easy to
download.
Every live session, quiz and payment leaves a record, because certification depends on
it.
Admin should be able to change content, batches and questions without code
changes.
Build modular so new features can plug in later without rework.
Tech stack and architecture
The stack is Next.js for the front end, NestJS for the back end API, and Neon (serverless
PostgreSQL) as the database.

Feature plan by module
The learner journey runs in this order, and each module below serves one part of it:
1. Visitor lands on whatboutme.com and picks a program.
2. Signs up, pays through Stripe, gets an invoice.
3. Signs the program agreement online.
4. Is placed in a batch and gets a welcome email with the first session.
5. Attends live classes and works through the 11 steps, each unlocked by passing the
previous step's quiz.
6. Takes the final written exam and the oral assessment.
7. Has the closing call, then receives a certificate after admin approval.
Course management (Super Admin)
Everything a learner can buy is set up by Super Admin from the panel, with no developer
involved. The platform must support many courses, not only 11 Steps to U.

Courses
Create, edit, duplicate, publish, unpublish and archive a course.
Course details: name, short and long description, cover image, category (certification,
workshop, corporate), delivery mode (online, in person, hybrid), duration, CPD hours,
language.
Course structure: add steps or modules, lessons, quizzes and final exam rules. A
course can have steps with unlock rules (like 11 Steps) or be a simple open course (like
a one-day workshop).
Choose which features the course uses: quizzes, final exam, oral assessment,
attendance requirement, agreement, certificate type.
Assign a certificate template and an agreement template per course.
Each published course automatically gets its own page on the website.
Pricing and registration
Set one or more prices per course (INR, AED, USD), early bird price with an end date,
and optional instalment plans.
Create coupons: percentage or fixed, per course or all courses, usage limit, expiry date.
Open or close registration per course or per batch. Set a registration deadline and seat
limit, with a waitlist when full.
Custom registration form fields per course (for example company name for corporate,
city for in-person workshops).
See all registrations per course: paid, pending payment, agreement pending, enrolled,
cancelled, refunded.
Add a learner manually (offline payment or complimentary seat) and mark the
payment method.
Corporate registration: one company pays for several participants, each gets their own
login.
Batches per course
Create batches under a course, each with its own start date, schedule, capacity,
manager and price if different.
Learners register for a specific batch, or are auto-placed into the next open batch.
Invoices and payments
Invoice settings: company details, logo, invoice number format and sequence, tax fields
(VAT for UAE, GST for India if applicable), footer notes.

3. Batch management

start date, capacity, assigned manager, session schedule.
New paid learners are placed into the open batch automatically, or moved manually by
admin.
A batch has its own session calendar, announcements, attendance sheet and progress

Move a learner between batches without losing progress. Close or archive a finished
batch.
Batch-wide actions: send announcement, send reminder, export attendance and
progress.
4. The 11 Steps program (learning modules)
Program is built as 11 steps. Each step holds lessons (video, PDF, audio, text) in a set
order, plus a 10-question quiz at the end.
Step unlock rule: the next step opens only when the previous step's lessons are
complete and its quiz is passed. Admin can also set a date-based release per batch if
needed.
Lesson completion is tracked (video watched to a set percentage, PDF opened, audio
played).
Admin can manually unlock or re-lock a step for one learner, with a logged reason.
Content is managed in Roweena's Studio: upload, reorder by drag and drop, preview as
a learner, publish or keep as draft.

5. Resource library
A separate library of extra material (worksheets, readings, guided audios), organised
by category and tagged by step.
Access can be set per program, per batch or per step.
View only: no download buttons, files open inside the platform viewer. See the content
protection section.
6. Quizzes, exams and assessment
Question bank managed by admin, tagged by step. Multiple choice to start, with room
for other types later.
Step quizzes: 10 questions each, pass mark set by admin, retry limit and wait time
between retries set by admin.
Final written exam: 50 questions drawn and shuffled from the bank, so each retake
gives a different paper. Time limit set by admin.
Oral assessment: booked as a session, scored by admin against a simple rubric, with
notes stored on the learner's record.
Learners see their score and which step to revisit. Admin sees results per learner and
per batch.
7. Live classes and sessions
Admin or manager schedules a session for a batch or books a 1:1. The meeting link
(Zoom or Google Meet) is created automatically and added to Roweena's Outlook
calendar.
Booking types from the proposal, each with a fixed length and automatic naming: 11
Steps Welcome Call, 11 Steps Closing Call, 1:1 with Ro, Vision Board Workshop (online or
in person), Vision Board Online, Speaker Discovery Call.
Learners book slots from Roweena's available times, shown in their own time zone.
Reschedule and cancel rules set by admin.
Session page shows join button (active shortly before start), agenda and materials.
After the class, admin uploads the recording or it is pulled from Zoom automatically.
Recordings play in the view-only player for that batch.

8. Attendance tracking
For online sessions, attendance is pulled from the Zoom or Google Meet participant
report after the meeting: join time, leave time, minutes present.
Match participants to learners by email. Unmatched names go to a review list for the
manager to link.
A minimum attendance rule (for example 75% of session time) decides "present". Set
by admin.
For in-person workshops, a check-in link or QR code marks attendance.
Manager can correct attendance manually, with a logged reason.
Attendance feeds certificate eligibility and the learner's dashboard.
9. Learner dashboard and progress sharing
One screen showing: current step, progress %, CPD hours earned, next session,
pending quiz, invoices, agreement, certificates.
Progress sharing: learner can generate a public link or image card showing milestones
reached (for example "Completed Step 6 of 11"), and share it to LinkedIn, Instagram or
WhatsApp.
Learner chooses what the share shows. Nothing is public unless they create a share.
Certificates get a public verification page by certificate number, and an "Add to
LinkedIn profile" button.
10. Certificates
Issued only when all steps, quizzes, the final exam, oral assessment, required
attendance and the closing call are complete.
Held in a pending list until admin approves. Admin uploads and manages certificate
templates.
Generated as a PDF with learner name, program, date, CPD hours and certificate
number.
Corporate workshop track gets a separate certificate of participation with no exam or
CPD hours.
11. One-on-one chat
Private chat between a learner and the team (Roweena, admins, or the batch manager).
Text, emoji, file and image attachments. Read receipts and typing status.

Content protection
No web platform can fully stop a determined person from screen-recording, so the goal is
to make downloading hard and sharing traceable. Set this expectation with the client.
Videos
Stream through the video service with short-lived signed links, never a direct file URL.
Restrict playback to whatboutme.com so embed links do not work elsewhere.
Custom player with no download option and no right-click menu.
Moving watermark over the video with the learner's name or email, so any leak can be
traced.
Consider DRM from the video provider later if leaks become a real problem.
PDFs and audio
Shown in an in-app viewer (PDF rendered page by page), no download or print button.
Files served through the API with short-lived signed links, only to logged-in learners
with access to that step.
Light watermark with the learner's name on PDF pages.
Account sharing
Limit active sessions per learner (for example two devices). Logging in on a third
device signs out the oldest.

Non-functional requirements
Security: passwords hashed, login rate limits, role checks on the server for every
request, HTTPS only, secrets in environment settings, input validation on every form.
Privacy: learners are in the UAE and India, so store only what is needed, let a learner
download or delete their data on request, and keep a privacy policy and terms page.
Performance: pages usable on mid-range phones on mobile data. Lazy-load video,
compress images.
Time zones: store all times in UTC, show them in each user's own time zone.
Currency: support INR and AED or USD pricing per program.
Backups: daily database backups with point-in-time restore (Neon supports this). Test
a restore before go-live.
Monitoring: error tracking on front end and API, uptime checks, alerts to Foxwel.AI.
Accessibility: readable font sizes, captions support on videos, keyboard-friendly
forms.
Handover: source code in a repository owned by the client or shared with them, setup
guide, admin user guide, and a training session for Roweena's team.
